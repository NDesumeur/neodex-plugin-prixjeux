# Prix des jeux

Les jeux gratuits de la semaine sur l'Epic Games Store, les promos Steam du moment en euros, et ta liste de jeux à surveiller avec une alerte quand le prix descend sous ton seuil.

GRATUITS : les jeux offerts en ce moment et ceux de la semaine prochaine. PROMOS STEAM : les réductions mises en avant par Steam, du plus gros pourcentage au plus petit. MA LISTE : cherche un jeu Steam, choisis ton prix ; la liste est vérifiée toutes les 3 heures et une notification NeoDex arrive quand le prix est atteint ou qu'un nouveau jeu gratuit sort.

Ses données (réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Prix des jeux → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
